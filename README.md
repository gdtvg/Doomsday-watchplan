### 🌟 Kernfunktionen im Überblick

1. **🎬 Kinoreifes Streaming-Billboard (Hero Carousel)**
   - Hochauflösende Key-Art-Backdrops und Filmlogos.
   - Trailer-Vorschau mit integrierter Ton- & Wiedergabesteuerung.
   - Exklusive Metadatenanzeige (4K Ultra HD, Dolby Vision, Kino- & Streaming-Status).

2. **⚡ Doctor Doom Mode & Inkursions-Filter**
   - Schalte mit einem Klick auf die **32 Doomsday Essentials** um — die essenziellen Titel, die man für *Avengers: Doomsday* wirklich gesehen haben muss.
   - Farblich hervorgehobene Latveria-Smaragdgrün- & Incursion-Designelemente.

3. **🗺️ Multiversum Inkursions-Radar (Interactive Map)**
   - Grafische Visualisierung kollidierender Universen: **Earth-616** (MCU), **Earth-10005** (Fox X-Men), **Earth-1960s** (Fantastic Four: First Steps), **Earth-838** (Illuminati) und die **Leere (The Void)** am Ende der Zeit.
   - Inkursions-Warnstufen, Ankerwesen-Status und Bedrohungsanalysen.

4. **⏱️ Interaktiver Marathon-Planer**
   - Berechne genau, wie viele Stunden pro Woche du schauen musst, um pünktlich zum Kinostart am **1. Mai 2026** vorbereitet zu sein.
   - Wöchentlicher Zeitplan, verbleibende Laufzeit in Stunden und Echtzeit-Fortschrittsbalken.

5. **🧭 3 Ausgewählte Watch-Routen**
   - **Route 1: Doomsday Express-Pfad** (~35 Stunden): Nur die absolute Pflicht (Loki TVA, Multiverse of Madness, Deadpool & Wolverine, Fantastic Four).
   - **Route 2: MCU Chronologie** (Inkl. Infinity Saga & Multiverse Saga).
   - **Route 3: Komplettes Multiversum** (MCU + X-Men + Spider-Man + Fantastic Four + Blade).

6. **🎯 Tier-Listen & Wissensdatenbank**
   - Ranke Filme in interaktiven Tier-Listen (S, A, B, C, D).
   - Detaillierte Post-Credit-Szenen-Erklärungen mit Spoiler-Schutz.
   - Vollständige Streaming-Anbieter-Badges (Disney+, Netflix, Prime Video, Kino).

## 🛠️ Technische Architektur

- **Framework**: [React 18](https://reactjs.org/) mit [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animationen**: [Motion (Framer Motion)](https://motion.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Audio Effects**: Web Audio API Synthesizer (Klick-, Chime- und Alarm-Effekte)
- **Persistenz**: Browser `localStorage` (keine externen Tracker oder Accounts nötig)

## 🚀 Installation & Lokale Entwicklung

```bash
# 1. Repository klonen
git clone https://github.com/dein-user/avengers-doomsday-hub.git

# 2. In das Verzeichnis wechseln
cd avengers-doomsday-hub

# 3. Abhängigkeiten installieren
npm install

# 4. Entwicklungsserver starten
npm run dev
```

Die Anwendung ist anschließend unter `http://localhost:3000` im Browser erreichbar.

### Produktions-Build erstellen

```bash
npm run build
```
